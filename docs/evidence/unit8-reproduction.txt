ADDITIONAL BOUNDARY INVESTIGATION

Called the existing verify_password("password", stored_hash) for each value:

stored_hash = "not_a_valid_bcrypt_hash"
Observed: UnknownHashError: hash could not be identified

stored_hash = ""
Observed: UnknownHashError: hash could not be identified

stored_hash = "$2b$12$invalid"
Observed: ValueError: salt too small (bcrypt requires exactly 22 chars)

stored_hash = "5f4dcc3b5aa765d61d8327deb882cf99"
Observed: UnknownHashError: hash could not be identified

The installed UnknownHashError inherits from ValueError. A recognized bcrypt
prefix with invalid contents can raise ValueError directly, so the plan must
cover both failure paths. All values here are synthetic test data.
